# SecureRegent Business Performance & Revenue Analytics Dashboard

An interactive business analytics dashboard built with React and Vite for exploring business performance, revenue, leads, quotations, deals, orders, and payments.

## Features

- Business KPI cards and analytics charts
- Date filters: Today, Last 7 Days, Last 30 Days, and Custom Range
- Previous-period comparisons
- Searchable record lists and interactive drill-downs
- Linked lead, quotation, deal, order, and payment records
- CSV export for dashboard reports and filtered record lists
- Responsive dashboard layout

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Local dummy business dataset

## Getting Started

Requirements: Node.js and npm.

1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in your terminal.

## Production Build

Run `npm run build`. The production files are generated in the `dist` directory.

## Data Notice

This project uses dummy data for demonstration and internship assignment purposes. It does not connect to a production database or backend.
